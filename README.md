# InvoiceFlow

### Modern Offline Invoice Management Dashboard

InvoiceFlow is a modern, responsive, and offline-ready invoice management web application built with **HTML, CSS, and Vanilla JavaScript**.

It allows businesses, shops, freelancers, and individuals to create professional invoices, manage taxes, track payments, generate QR codes, print invoices and shipping labels, and export invoice data.

The application is designed to run directly in a web browser without requiring a backend server or database.

## 🌐 Deploy with GitHub Pages

You can easily deploy InvoiceFlow using GitHub Pages.

### Step 1

Upload the project to a GitHub repository.

### Step 2

Open your GitHub repository.

Go to:

```text
Settings → Pages
```

### Step 3

Under **Build and deployment**:

Select:

```text
Source → Deploy from a branch
```

### Step 4

Choose:

```text
Branch → main
Folder → / (root)
```

### Step 5

Click:

```text
Save
```

GitHub will generate a live website URL.

Example:

```text
https://your-username.github.io/InvoiceFlow/
```

Your InvoiceFlow application will then be available online.

## 🔐 Data Storage

InvoiceFlow uses Browser LocalStorage.

This means:

* Data is stored inside your browser.
* No external database is required.
* No account registration is required.
* No backend server is required.

### Important

Clearing browser data may remove saved invoices.

It is recommended to regularly create a JSON backup.
